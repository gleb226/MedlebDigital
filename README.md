# ⚡ Medleb Digital

Сайт + Telegram бот для студії веб-розробки **Medleb Digital**.

## Структура

```
MedlebDigital/
├── server.js          # Головний файл (сервер + бот)
├── package.json
├── .env               # Токени і конфіг
├── .gitignore
└── public/
    ├── index.html     # Головна сторінка
    ├── css/
    │   └── main.css
    └── js/
        └── main.js
```

## Запуск

```bash
npm install
npm start
```

Або для розробки:
```bash
npm run dev
```

## Конфіг .env

```env
BOT_TOKEN=...
ADMIN_CHAT_ID=...   # Твій Telegram chat_id для отримання замовлень
PORT=3000
NODE_ENV=production
```

## Функціонал сайту

- Головна сторінка з описом та цінами
- Сторінка послуг з картками
- Портфоліо з фільтрацією
- Калькулятор вартості
- Форма зворотного зв'язку
- Темна / Світла тема
- SEO оптимізація
- Адаптивний дизайн

## Функціонал бота

- `/start` — головне меню
- Послуги та ціни
- Портфоліо проектів
- Калькулятор вартості
- Форма зворотного зв'язку (повідомлення приходять на ADMIN_CHAT_ID)
